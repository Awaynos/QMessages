# Как помочь проекту

**Русский** · [English](CONTRIBUTING.en.md)

Спасибо, что заглянул. QMessages — небольшой личный проект, и любая помощь
приветствуется: сообщение о баге, правка в одну строку, улучшение документации, идея.

## Что можно сделать

- **Сообщить о баге** — [открой issue](https://github.com/Awaynos/QMessages/issues/new) и напиши, как воспроизвести: что делал, что ожидал, что получил.
- **Починить баг** — даже если это одна строка.
- **Улучшить документацию** — README, скриншоты, эту инструкцию.
- **Предложить идею** — коротко и по делу, в issue.
- **Помочь с Linux/macOS** — пока в планах; напиши, если готов взяться.

## Перед началом

- Мелкую правку (опечатка, баг в одной функции) можно присылать сразу.
- Крупное изменение — сначала открой issue и опиши замысел. Так никто не потратит время зря.
- Проверь, нет ли уже открытого issue про это же.

## Как запустить у себя

```powershell
git clone https://github.com/Awaynos/QMessages.git
cd QMessages

setup.bat
start.bat
```

`setup.bat` создаёт `.venv` и ставит зависимости. `start.bat` запускает без консоли.

Или вручную:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py --settings
```

Нужен **Python 3.11+**. Сейчас поддерживается Windows 10/11; Linux и macOS — в планах.

## Проверки

Тестового фреймворка нет — проверяй вручную:

```powershell
.\.venv\Scripts\python.exe -m compileall -q .
.\.venv\Scripts\python.exe main.py --settings
.\.venv\Scripts\python.exe main.py --preview
```

Перед PR проверь: запуск, открытие настроек, хоткей, выбор и вставку, сохранение
заготовок. Если менял зависимости, иконку или структуру сборки — прогони
`build.bat` и запусти `dist\QMessages\QMessages.exe`.

Добавил функцию — опиши в PR, как её проверить.

## Стиль кода

- Python 3.11, аннотации типов, отступ 4 пробела.
- Комментарии — только там, где объясняют **почему**, а не **что**. Очевидное не комментируем.
- Интерфейс пока на русском; новые строки — по-русски. Локализация — в планах.
- Не смешивай слои: `main.py` — связка, `settings.py`/`wheel.py` — интерфейс, `hotkeys.py`/`winapi.py` — платформа, `config.py` — данные, `theme.py` — палитра.
- Палитра фиксированная — Metal. Не добавляй переключатель тем без обсуждения.
- Новую функцию делай отдельным модулем или небольшой функцией, не ломай существующие сигналы.

## Коммиты

Conventional Commits, по-английски, в повелительном наклонении:

```
feat(wheel): add hover label animation
fix(paste): restore clipboard after Enter
docs: update README
```

В скобках — область: `ui`, `wheel`, `hotkeys`, `paste`, `config`, `build`, `docs`.

## Ветки и pull request

- Ветка от `main`: `feature/короткое-название` или `fix/короткое-название`.
- В описании PR: что сделано, зачем и как проверить.
- Менял интерфейс — приложи скриншот.
- Один PR — одна задача.
